# M2 layer panel: blind UX score

Reviewer: blind, screenshots only (`docs/ux/scores/m2/*.png`) plus rubric §9. I did not read any source code, docs or git history. Anything that needs interaction is listed under "Not verifiable" and gets no credit.

## Not verifiable from screenshots

- Hotkeys: whether F2, Ctrl+D, S, Shift+L, Ctrl+E and the others work, and whether they work while hovering the viewport (target toggle, view mask, strength scrub).
- Inline rename.
- Modifier clicks on thumbs: Alt+click to view the mask, Shift+click to disable it, Ctrl+click for a popover.
- Thumb tooltips, and any tooltips at all.
- Live thumbnail updates (about 1 s).
- Ctrl+drag duplicate, spring-open folders, auto-scroll, multi-row drag order, Alt-recursive expand.
- Drag-reordering ops inside a mask stack (only the Order arrows are visible).
- Contents of the `Mask ▾` and `Op ▾` dropdowns, and the rest of the clipped context menus.
- Insert-above behaviour, and whether a new item is auto-selected and expanded.
- Refused-stroke feedback on a locked layer or a non-paintable op.
- Strength scrub by drag.
- Viewport radial menu, layer quick-switcher, and the 400 px pointer radius.
- Whether the viewport menus share the panel's menu definitions.
- AA contrast (it can't be measured precisely from crops).

## Latency guard (not part of the blind review)

|---|---|---|
